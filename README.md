# chessblues-social

Image host for [chessblues.com](https://chessblues.com) social posts.

Each folder is one scheduled post, named `<date>_<item_id>`, holding the
upload-ready JPEGs that get published to Instagram and TikTok. Posting tools
fetch them over `raw.githubusercontent.com`, which is why this repo is public:
a scheduler cannot read a private repo without credentials.

Nothing secret goes in here. Every image is one that is about to be posted
publicly anyway.

The PNG masters and the claim-gate evidence live in the main chessapp repo
under `marketing/out/`, not here.
